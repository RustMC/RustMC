# ADR-0001: Independent development and provenance

Status: **Proposed for owner adoption** (29 September 2026).

## Context and constraints
Core design must be independently developed, with source/data/license ledger. M0 has no gameplay implementation; compatibility and performance claims need evidence.

## Options considered
Copying competitor implementation or architecture; independent design using primary technical sources and reviewed general-purpose libraries.

## Decision
Use independent design and record origin, usage, and license before adoption.

## Consequences and risks
More original work and review effort; accidental source contamination remains a risk.

## Tests and replacement criteria
Reject material lacking provenance or permission; replace when an owner-approved policy offers equivalent traceability.
