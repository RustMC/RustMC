# ADR-0002: Java-rule baseline and separate gateways

Status: **Proposed; gameplay approval needed** (29 September 2026).

## Context and constraints
Java and Bedrock differ in protocol and some game behavior. M0 has no gameplay implementation; compatibility and performance claims need evidence.

## Options considered
One shared Java-style rule set with translation; Bedrock-native rules; separate worlds.

## Decision
Propose Java-style shared-world rules and distinct edition gateways.

## Consequences and risks
Bedrock translation has visible limits; parity must be scoped by version.

## Tests and replacement criteria
Test exact client versions and rule differences; replace if owner chooses another baseline before gameplay.
