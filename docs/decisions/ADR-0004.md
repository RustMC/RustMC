# ADR-0004: Reference executor and replay contract

Status: **Proposed** (29 September 2026).

## Context and constraints
Parallel scheduling must preserve semantic order and replay. M0 has no gameplay implementation; compatibility and performance claims need evidence.

## Options considered
Parallel-first; single-writer reference then compare.

## Decision
Build a single-authoritative-writer executor first in a later milestone, record versioned replay inputs and external results.

## Consequences and risks
Reference execution may be slower; it provides a comparison oracle but not vanilla truth.

## Tests and replacement criteria
Reject parallel mode on replay divergence; replace oracle only with a stronger proven reference.
