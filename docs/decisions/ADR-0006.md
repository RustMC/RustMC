# ADR-0006: Readiness and performance evidence

Status: **Proposed** (29 September 2026).

## Context and constraints
Process start and bound listeners do not establish playable readiness. M0 has no gameplay implementation; compatibility and performance claims need evidence.

## Options considered
Report only process time; separate process, bind, protocol, and first-playable-join events.

## Decision
Define distinct events and record raw workload/hardware/configuration data.

## Consequences and risks
Measurement work is required before claims.

## Tests and replacement criteria
Reject metrics that omit join, recovery, sample size, or workload; revise when real instrumentation exists.
