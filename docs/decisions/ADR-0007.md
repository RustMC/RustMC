# ADR-0007: Plugin boundary and isolation

Status: **Deferred** (29 September 2026).

## Context and constraints
Plugins must not gain unrestricted state mutation or unearned crash-isolation claims. M0 has no gameplay implementation; compatibility and performance claims need evidence.

## Options considered
In-process native, sandboxed, separate-process, or no plugins initially.

## Decision
Defer runtime selection; future plugins submit validated permission-controlled intents.

## Consequences and risks
API and performance remain unknown.

## Tests and replacement criteria
Select only after timeout, failure, ordering, permission, and compatibility tests.
