# ADR-0011: Local Java preview identity boundary

Status: **Proposed for the Java-only preview slice** (29 September 2026).

## Context
The owner requests a real Java 26.3 client preview before secure online authentication or a shared multiplayer world exists. Accepting an unverified username as a production identity would be misleading and unsafe.

## Decision
If a local preview login is implemented, require an explicit development setting and a loopback-only bind. Derive only an ephemeral session identity for the preview; do not call it authenticated, reuse it for permissions, or expose it on a remote listener. Logs must not print account tokens, full client payloads, or session secrets. Do not distribute a binary or claim Java multiplayer support from this path.

## Consequences and tests
Local users can impersonate names, so this path cannot establish account ownership. Tests must cover disabled-by-default behavior, remote-bind rejection, malformed names and packets, version mismatch, disconnect, and shutdown. Replace this path or keep it isolated before any remote or public server support.
